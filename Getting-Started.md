# 🚀 Getting Started

> Get Agent 24 running on your Android device in under five minutes.

---

## 📱 Requirements

| Requirement | Details |
|---|---|
| 🤖 OS | Android 8.0 (Oreo) or newer |
| 💾 Storage | ~100 MB free |
| 🌐 Network | Internet connection for AI providers |
| 🔑 API key | Any supported provider — free tiers available |

---

## ⚙️ Setup in 4 Steps

### 1️⃣ Install
Install Agent 24 on your Android device.

### 2️⃣ Connect a provider
Run `/connect`, pick a provider from the list, and paste your API key.
Credentials stay on your device and are never shown in chat.

### 3️⃣ Choose a model
Run `/model` and select the model that fits your task and quota.

### 4️⃣ Start working
Describe what you want in natural language. Agent 24 plans, executes,
verifies, and reports.

---

## 💬 First Conversation

```text
you   > build a script that renames all images in a folder by date
agent > plan → create script → run it → verify output → report ✅
```

---

## 🧭 Useful First Commands

| Command | What it does |
|---|---|
| `/new` | Start a fresh session |
| `/sessions` | Show all sessions |
| `/build` | Switch to full-access Build mode |
| `/plan` | Switch to read-only Plan mode |
| `/help` | Show all commands |
