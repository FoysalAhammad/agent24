🌟 What is Agent 24?

Agent 24 is not just a chatbot — it is a full agentic workspace that runs entirely on your Android device. It reads your request, forms a plan, calls the right tools, verifies the result, and reports back, all while keeping you in control through an explicit permission model.

💡 Think of it as a complete engineering companion that travels with you: write code, debug scripts, research documentation, automate shell work, or explore any idea — on the go.

✨ Highlights
🧠 Truly agentic Plans, executes, verifies and iterates — not just replies.
🔧 18 built-in tools Shell, files, search, patches, web, git, tasks, vision and more.
🔐 Permission-first Every sensitive action is allow / ask / deny — you decide.
🌍 Model-agnostic Works with 13+ pre-configured providers and dozens of models.
📴 On-device memory Sessions, history and databases live locally on your device.
🌐 Multilingual Understands and replies in your language.

🚀 Getting Started

Get Agent 24 running on your Android device in under five minutes.

📱 Requirements

Requirement Details
🤖 OS Android 8.0 (Oreo) or newer
💾 Storage ~100 MB free
🌐 Network Internet connection for AI providers
🔑 API key Any supported provider — free tiers available

⚙️ Setup in 4 Steps

1️⃣ Install

Install Agent 24 on your Android device.

2️⃣ Connect a provider

Run /connect, pick a provider from the list, and paste your API key. Credentials stay on your device and are never shown in chat.

3️⃣ Choose a model

Run /model and select the model that fits your task and quota.

4️⃣ Start working

Describe what you want in natural language. Agent 24 plans, executes, verifies, and reports.

🤖 Agents

Agent 24 ships with a layered agent system — pick the right brain for the job.

🎯 Primary Agents

Agent Mode Best for
Build Full access Real work: editing, running, shipping.
Plan Read-only + ask Analysis and review before touching anything.

🛠️ Subagents

Agent Role
General Autonomous multi-step tasks delegated by the main agent.
Explore Fast, read-only codebase search and summarisation.
Scout External documentation and dependency research.

⚙️ System Agents (automatic)

Agent Trigger What it does
Compaction Context grows long Summarises history to keep the session healthy.
Title First message Generates a short session title.
Summary Session switch Writes a conversation summary.

🔁 How they work together

Typical flow — click to expand 1. You send a request in **Build** or **Plan** mode. 2. The main agent plans and, if needed, delegates research to **Explore** / **Scout**. 3. **General** handles heavy multi-step subtasks. 4. **Compaction** keeps context clean automatically. 5. **Title** / **Summary** organise your sessions in the background.

🔐 Permissions

Safety by design: nothing sensitive happens without your rules allowing it.

🎛️ The Three Values

Value Behaviour
✅ allow Execute immediately
❓ ask Show a confirmation dialog, wait for your decision
🚫 deny Block entirely

❓ FAQ

🤖 What exactly is Agent 24?

An autonomous AI coding & technical assistant for Android — a full agentic workspace with planning, tools, permissions and multi-provider support.

📱 Which devices are supported?

Any Android 8.0 (Oreo) or newer device with ~100 MB of free storage.

🔑 Do I need an API key?

Yes — connect any supported provider with /connect. Many providers offer free tiers. Your key stays on your device.

🧠 Can it work without internet?

Session history and files are fully local, but AI model calls need a connection to your chosen provider.

🔐 Is my data safe?

Every sensitive action goes through the allow / ask / deny permission model, and credentials are never shown in chat or exports.

🌐 Which languages does it understand?

It replies in your language — including English, Bangla and Hindi.

🔧 Can I add my own tools or skills?

Yes — load custom skills and commands from your configuration directory.
