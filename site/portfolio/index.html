About

Who I am

I'm Foysal Ahammad, a developer focused on Android and AI agent systems. I like building tools that make developers faster — apps you can actually use on a phone, with no server lock-in.

My main project, Agent 24, is an autonomous AI coding and technical assistant for Android: a full terminal, code editor, 31 built-in tools, 13 model providers and a permission system — all running locally on the device.

  • Full-stack web (HTML, CSS, JS, Python)
