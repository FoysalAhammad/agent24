# 🔧 Tools

> One unified tool layer the model can call during any conversation.

## 🧰 The 18 Built-in Tools

| # | Tool | Purpose |
|---|---|---|
| 1 | `bash` | Execute shell commands |
| 2 | `shell` | Interactive shell sessions |
| 3 | `read` | Read files |
| 4 | `write` | Create / overwrite files |
| 5 | `edit` | Find & replace in files |
| 6 | `grep` | Regex content search |
| 7 | `glob` | Find files by pattern |
| 8 | `list` | List directories |
| 9 | `diff` | Unified diffs |
| 10 | `apply_patch` | Apply patch files |
| 11 | `webfetch` | Fetch URL content |
| 12 | `websearch` | Search the web |
| 13 | `task` | Delegate to subagents |
| 14 | `skill` | Load specialised skills |
| 15 | `question` | Ask you interactive questions |
| 16 | `todowrite` | Structured task list |
| 17 | `todoread` | Read the task list |
| 18 | `git` | Git status, diff, commit, branch… |

---

## 🌟 Extended Capabilities

- 🖼️ **Vision** — image inspection, colour probing, screenshot understanding
- 📱 **UI understanding** — dump on-screen element hierarchies
- ✅ **Todo tracking** — visible, structured progress for multi-step work
- 🤝 **Delegation** — spawn subagents for long autonomous tasks
